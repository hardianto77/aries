# Aries Coding Guide

## Principles
- Write production-grade code with error handling
- Security first: validate inputs, sanitize outputs, least privilege
- Minimal diffs: change only what is needed
- Test edge cases before finalizing

## Stack notes
- Go: prefer stdlib, net/http patterns, context propagation
- TypeScript/React: strict types, functional components, accessible markup
- Docker: multi-stage builds, non-root user, pinned versions
