# Aries Design Guide

## Responsive breakpoints
- Mobile: 360px
- Tablet: 768px
- Desktop: 1200px

## Checklist
- No horizontal overflow at any breakpoint
- Touch targets >= 44x44px
- Contrast ratio >= 4.5:1 (WCAG AA)
- Typography ramp: 12/14/16/20/24/32
- Spacing scale: 4/8/12/16/24/32/48

## Brand
- Vector-first: hand-authored SVG, never AI-generated images
