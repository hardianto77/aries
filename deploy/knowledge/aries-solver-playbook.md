# Aries Problem Solving Playbook

1. Restate the problem in one sentence
2. List constraints and knowns
3. Enumerate hypotheses ranked by likelihood
4. Design the cheapest test per hypothesis
5. Execute, observe, eliminate
6. Conclude with an actionable plan and follow-ups

## RCA templates
- 5 Whys
- Fishbone (people/process/tech/environment)
- Differential diagnosis
